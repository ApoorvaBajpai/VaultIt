⛓ Anchor to Blockchain

POST /documents/anchor — Builds Merkle tree over all unanchored documents and submits root to Polygon Amoy.

POST /documents/anchor

This will batch all documents with merkle_root = NULL and anchor them in a single blockchain transaction. No body required.

✅ Verify Document

GET /documents/{id}/verify — Recomputes SHA-256 from disk and checks Merkle root on-chain. This is your tamper-detection demo.

GET /documents/{doc_id}/verify
